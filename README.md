Análisis de Portafolios de Inversión con Python
Financial Portfolio Analysis with Python

Herramientas de análisis financiero desarrolladas con Python para comparar,
evaluar y optimizar portafolios de inversión en mercados bursátiles.

Financial analysis tools built with Python to compare, evaluate and optimize
investment portfolios in stock markets.

Proyectos / Projects

Análisis Bursátil / Stock Market Analysis
- **Screener de Acciones / Stock Screener** — Detects the best opportunities in Mexican and US markets automatically
- **Análisis Técnico / Technical Analysis** — MA20/MA50 moving averages, automatic buy and sell signals
- **Monitor de Mercado / Market Monitor** — Real-time tracking of BMV and NYSE stocks

Gestión de Portafolios / Portfolio Management
- **Comparador de Portafolios / Portfolio Comparator** — Compares performance, risk and final value after taxes
- **Tracker en Tiempo Real / Real-Time Tracker** — Live portfolio monitoring
- **Calculadora de Rendimientos / Returns Calculator** — Profit projection with custom initial capital

Reportes y Visualización / Reports & Visualization
- **Dashboard Financiero / Financial Dashboard** — Professional Bloomberg-style charts
- **Reporte Automático / Automatic Report** — Analysis reports ready to present to clients
